The solution

A gate before the build, with a person in charge

Promptplain words, or voice
→
Clarifyat most 3 rounds; rules pick the questions
→
Evidenceevery report in scope, cited rows
→
Decisionreuse, repair, extend, migrate, retire, build
→
Gates7 checks block release
→
Approveowner and review date

Rules decide. Deterministic, cited, repeatable and auditable. If every model is down, the decisions stay the same.

AI reads and words. It reads messy requests, phrases questions and explanations, and answers in a request's chat. A faithfulness guard drops any claim not in the decision.

Mapped to Bayer's flow: Prompt-to-Intent, Intent-to-Evidence, Evidence-to-Spec, Spec-to-Report3

Least privilege

Everyone gets their own app, and only their own data

BusinessAsks, gets one plain answer with audio; sees only their own requests
AnalystCited evidence; dashboard studio fills a request's spec with real rows (render_preview), drag and drop, export
DeveloperProposes rule and vocabulary changes, each measured on 150 requests
ApproverGates, what-if owner fix, approval with owner and review date
ExecutiveOne-page report in plain words, a source under every section; print or email
OperatorWall screen for gloves and distance: what is broken now and who to call
AdminWorkflows and email through n8n, with an outbox of every message

Enforced by the API on every endpoint, not hidden in the UI. Approver names are hidden from those who do not decide.

Reuse Gate7

Red Hat OpenShift AI

Served, gated and observable on OpenShift AI

Web app

React UI, one app per role. Sign-in by role code; the top bar shows where each decision ran.

Reuse Gate API

Python, non-root, read-only container, state volume. Least privilege on every endpoint. Falls back to in-pod rules and says so.

KServe InferenceService

The decision service as a served model on its own ServingRuntime, listed in the OpenShift AI dashboard.

OpenShift Pipelines

Tekton run before every rollout: unit tests, governance gate, evaluation gate, security gate, rollout.

Model tiers

gpt-oss-120b, then GLM-5.2, then rules, with a circuit breaker. Models read and word; they never decide.

n8n and ElevenLabs

Email for approvers, requesters and developers; a weekday radar digest; Listen in plain language.

380 backend and 187 front-end tests. Live: reuse-gate-ui-ztothez-dev.apps.rm1.0a51.p1.openshiftapps.com
